# Data Points to Extract for POC

## From investment-style documents: IFC / ADB / SEC

| Category | Data points |
|---|---|
| Deal identity | project name, company name, country, region, sponsor, sector, technology |
| Asset profile | technology, capacity MW, capacity MWh, development stage, COD, asset life |
| Transaction profile | equity stake, debt/equity mix, investment amount, project cost, financing source |
| Revenue assumptions | tariff, PPA tenor, merchant exposure, generation, capacity factor, availability, curtailment |
| Valuation / returns | IRR, NPV, payback, EV, EBITDA, EV/EBITDA, EV/MW, leverage, DSCR |
| Risk | construction, technology, offtaker, counterparty, curtailment, FX, inflation, regulatory, legal, ESG |
| Sensitivities | price curve, capex, opex, delay, FX, inflation, generation, capacity factor |
| Source traceability | document name, page/slide number, cell range where available, URL |

## From NREL ATB

| Category | Data points |
|---|---|
| Technology benchmark | technology, technology detail, year, scenario |
| Cost benchmark | overnight capital cost, capex, fixed O&M, variable O&M |
| Performance benchmark | capacity factor, LCOE, economic life, WACC |
| Storage benchmark | battery duration, augmentation/replacement assumptions where available |

## From WDI / IRENASTAT

| Category | Data points |
|---|---|
| Macro | GDP growth, inflation, exchange rate, GDP current USD |
| Renewable market | installed capacity, electricity generation, technology, grid connection, country, year |

## From World Bank PPI

| Category | Data points |
|---|---|
| Comparable project | project name, country, region, sector, subsector, technology, capacity MW, financial closure year |
| Investment benchmark | investment commitment, private participation type, sponsor, debt provider, government/development bank support |

## From SEC EDGAR

| Category | Data points |
|---|---|
| Financials | revenue, operating income, net income, assets, debt, capex, cash |
| Narrative RAG | business description, strategy, risk factors, market risk, MD&A, renewable/battery discussion |
| Source | CIK, ticker, filing date, accession number, filing URL |
